Impacto de Tiempo

Análisis de Impacto de Tiempo

¿Qué es?

El Time Impact Analysis (TIA) es una metodología estandarizada en la práctica recomendada "AACE 52R-06 Prospective Time Impact Analysis - As Applied in Construction" para analizar y cuantificar el impacto de eventos en el cronograma de un proyecto.

Esta técnica es ampliamente reconocida en la industria de la construcción y gestión de proyectos como el método más riguroso y defendible para demostrar cómo eventos específicos afectan la fecha de finalización del proyecto.

¿Cómo funciona?

El principio fundamental del TIA es comparar el cronograma antes y después de un evento para determinar su impacto real. El proceso sigue estos pasos:

  1. Establecer la línea base: Se toma el cronograma actual como punto de referencia.
  2. Insertar el evento: Se modifica el cronograma para reflejar el evento (retraso, trabajo adicional o suspensión).
  3. Recalcular el cronograma: Se aplica el método de la ruta crítica (CPM) al cronograma modificado.
  4. Comparar resultados: Se comparan las fechas de finalización para cuantificar el impacto en días.

¿Qué hace esta aplicación?

Esta herramienta implementa el algoritmo TIA permitiéndote analizar tres tipos de eventos:

Retraso de tarea
Aumenta la duración de una tarea existente. Útil para modelar situaciones donde una actividad toma más tiempo del planificado debido a problemas técnicos, condiciones climáticas adversas u otros factores.
Tarea adicional
Inserta una nueva tarea en el cronograma después de una tarea existente. Aplica para trabajo correctivo, cambios de alcance o actividades no previstas que deben ejecutarse antes de continuar con las tareas sucesoras.
Suspensión de tarea
Divide una tarea en dos partes con un período de suspensión en medio. Modela situaciones donde el trabajo debe detenerse temporalmente por espera de permisos, aprobaciones, materiales o resolución de conflictos.

Resultados del análisis

Para cada evento analizado, la aplicación proporciona:

  • Comparación de fechas de finalización (línea base vs. impactada)
  • Impacto total en días del proyecto
  • Identificación de si el evento afecta la ruta crítica
  • Detalle de cambios en las holguras de todas las tareas afectadas

Esta información es esencial para la toma de decisiones, negociación de extensiones de plazo, análisis de reclamos y documentación de impactos durante la ejecución del proyecto.
